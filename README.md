# Koi McFarland - Personal Portfolio

My personal portfolio website, based on the [vCard template](https://github.com/codewithsadee/vcard-personal-portfolio) by codewithsadee. A fully responsive single-page portfolio built with plain HTML, CSS, and JavaScript.

Live site: https://koi-mcfarland.github.io (update once deployed)

## Contents

- **About** — who I am: Computer Science Engineer, self-taught programmer, and AI trainer
- **Resume** — education (Charleston Southern University), experience (DataAnnotation, NIWC/Core4ce, IEEE RE 2026 research), and skills, with a [link to my full resume PDF](./assets/pdf/resume.pdf)
- **Portfolio** — projects: TrueSizeOfGames, Falling Sand Simulation, and OntologyWeb
- **Contact** — email and message form

## Local development

No build step required. Just open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8080
```
